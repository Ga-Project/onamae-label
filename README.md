# おなまえ工房

入園・入学準備の「名前つけ」を時短する、無料のブラウザツールです。子どもの名前と持ち物・枚数を入れると、市販のラベルシートやA4普通紙に **mm単位でぴったり面付け** した印刷用の台紙をその場で作ります。あとは印刷して、破線に沿ってはがして貼るだけ。

名前や持ち物の文字数に合わせて文字の大きさを自動で調整し、フリガナも小さく添えられます。えんぴつのような細かい持ち物は「枚数」を入れるだけで必要な数だけ並びます。市販シートの位置が実機プリンタで少しずれても、mm単位の「位置の微調整」で合わせられます。

**入力した名前や持ち物は、この端末（ブラウザ）の中だけで処理します。サーバーへは送信しません。** 登録もインストールも不要です。

## こんな人に

- 入園・入学準備で、算数セットや文具の名前つけに時間がかかっている
- 手持ちのラベルシートに合うレイアウトが作れず困っている
- 印刷して自宅プリンタですぐに用意したい

## 使い方

1. 名前（ひらがな・漢字どちらでも）と、必要ならフリガナを入れる
2. 持ち物と枚数を入れる（空にすると名前だけのラベルで敷き詰めます）
3. ラベルシート、またはA4普通紙（フリー配置）を選ぶ
4. 「印刷 / PDFで保存」で出力し、破線に沿ってはがして貼る

印刷設定は倍率を「実際のサイズ / 100%」にし、「用紙に合わせる」は外してください（縮小されると位置がずれます）。本番の前に普通紙で試し刷りするのがおすすめです。

## できること・できないこと

- できる: 名前・持ち物ラベルの面付け、文字の自動縮小、フリガナ配置、A4普通紙・代表的なラベルシートへの印刷、印刷位置の微調整
- まだできない: 算数セットの極小ラベル専用プリセット、対応シートの全規格対応、フォントやフチの切り替え

## 開発

Next.js（App Router）。`out/` への static export で配信するためサーバーは不要です。

```bash
./setup.sh     # 依存の導入
pnpm dev       # http://localhost:3000（ホットリロード）
pnpm build     # out/ に静的 HTML/CSS/JS を生成
pnpm test      # node --test（面付けエンジンのユニットテスト）
```

面付けの座標計算と文字自動縮小は `app/lib/imposition.ts`、ラベル規格は `app/lib/labels.ts` にあります。
